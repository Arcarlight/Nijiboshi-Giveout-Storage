# 《想要飞的始祖小鸟》公开素材库

这里是《想要飞的始祖小鸟》（TBTAK）的公开素材，**随便拿去用**——做游戏、做视频、做网站都行，
不用提前问我一声。

## 里面有什么

| 目录 | 内容 |
| --- | --- |
| `tbtak/sprite/` | 点阵图：角色行走图、战斗图（按固定格切） |
| `tbtak/portrait/` | 敌人 / 角色的小型立绘，约 500×500 |
| `tbtak/ui/` | UI 素材：图标、窗框、按钮底图 |
| `audio/midi/` | MIDI：BGM 骨架 |

## 怎么下载

- **单个文件**：进对应文件夹，点文件名右侧的 Download
- **整包**：到 [Releases](../../releases) 下 zip（还没出包的话就先单个下）
- **带预览的素材页**：<https://arcarlight.github.io/BlogStand/resources/>
  （能看缩略图、点开大图、一键复制署名）
